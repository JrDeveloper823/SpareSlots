# SpareSlot website

A responsive Next.js starter website for SpareSlot — a marketplace concept that helps local service businesses fill last-minute appointment cancellations.

## Run locally

1. Install [Node.js](https://nodejs.org/) (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Visit http://localhost:3000.

## What's included

- Responsive marketing homepage
- Customer and business-focused calls to action
- Example nearby last-minute appointment cards
- Interactive "I'm a customer / I run a business" tab
- Mobile navigation and email sign-up demo feedback

## Important

This is a front-end MVP starter. Forms currently show demo confirmations and do not save data or send emails. Real accounts, live availability, bookings, notifications, payments and a database still need to be connected before launch. No real businesses or appointments are represented by the sample listings.

## Suggested next build steps

1. Connect Supabase for accounts, businesses, services and appointment slots.
2. Add verified business onboarding and live slot management.
3. Implement booking rules and cancellation handling.
4. Add email/SMS notifications.
5. Add Stripe only after validating the pricing model.
